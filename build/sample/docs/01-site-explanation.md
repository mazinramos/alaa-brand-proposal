# شرح موقع وشلي (عينة)

هذا الملف تجريبي لاختبار أداة البناء، يخدم المشرف فقط، والمحتوى فيه وهمي.

## ما هو الموقع؟

الموقع متجر إلكتروني كامل يعرض المنتجات ويستقبل الطلبات، وتديره صاحبة المتجر من لوحة تحكم (Admin Panel) بسيطة. هذه الفقرة طويلة قليلاً لنرى كيف يتصل الحرف العربي وكيف يلتف السطر داخل الصفحة، وفيها كلمات إنجليزية مثل Firestore (قاعدة البيانات) و Cloudflare وأرقام مثل 7-10 أيام و 2026.

### الصفحات الرئيسية

- الصفحة الرئيسية وفيها الأقسام المميزة
- صفحة المنتج مع الصور والمقاسات
- سلة الطلب وإتمام الطلب عبر واتساب
  - قائمة فرعية للتجربة
  - بند آخر فيه `code-sample` بخط لاتيني

1. الخطوة الأولى: فتح المتجر
2. الخطوة الثانية: اختيار القطعة
3. الخطوة الثالثة: إرسال الطلب
