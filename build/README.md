# أداة بناء ملفات الـ PDF

تحوّل ملفات Markdown في `docs/` إلى ملفي PDF بهوية وشلي (A4، عربي RTL، خط Cairo وGreat Vibes) في `final/`.

## المتطلبات

Python 3.10 أو أحدث، ومتصفح Chromium عبر Playwright. الخطوط **مضمّنة** في `build/fonts/` (من حزم npm)، فلا يلزم إنترنت وقت البناء.

```bash
pip install -r build/requirements.txt      # markdown, pypdf, playwright
playwright install chromium                # مرة واحدة فقط
```

> لازم Chromium 131 أو أحدث (Playwright 1.49+) لأن الهيدر والفوتر وترقيم الصفحات يعتمدان على `@page` margin boxes. التجربة تمت على Playwright 1.56.

## التشغيل

```bash
python build/build.py            # يبني الملفين الحقيقيين في final/ لو كل ملفات docs/ موجودة، وإلا يبني العينة
python build/build.py --real     # حقيقي فقط: يتوقف برسالة واضحة لو في ملف ناقص
python build/build.py --sample   # العينة فقط → build/sample/out/
python build/build.py --date 2026-11-02   # تاريخ الغلاف (الافتراضي تاريخ اليوم)
```

عند التشغيل من غير خيارات، وفي حال نقص أي ملف من `docs/`، الأداة تطبع تحذيراً وتبني العينة بدل الحقيقي. للمشرف: استعمل `--real` لتتأكد أنك لا تبني العينة بالخطأ.

## ما الذي تفعله الأداة

- **الغلاف:** خلفية موف غامق، "Alaa Mahjob" بخط Great Vibes، عنوان الملف، "مُعدّ لـ: ألاء محجوب | Alaa Mahjob"، والتاريخ. بدون هيدر/فوتر.
- **الفهرس:** يُبنى تلقائياً من `#` و`##` و`###` مع أرقام الصفحات (الرقم هو رقم الصفحة في الـ PDF، والغلاف هو الصفحة 1). الأداة تبني الملف مرتين لتصحح الأرقام.
- **الهيدر والفوتر:** عنوان الملف + Alaa Mahjob في الأعلى، ورقم الصفحة في الأسفل.
- **قص ملاحظات المشرف:** من السطر `## ملاحظات للمشرف` إلى نهاية الملف لا يدخل الـ PDF.
- **منع الكسر:** العنوان لا يبقى وحده آخر الصفحة، والصف في الجدول لا ينقسم، ورأس الجدول يتكرر لو امتد لصفحة ثانية، وصناديق الملاحظة والبطاقات لا تنقسم.

## صيغ Markdown المدعومة

| الصيغة | النتيجة |
|---|---|
| `# عنوان` | عنوان الملف (يبدأ صفحة جديدة، وأول فقرة بعده تظهر كنص تمهيدي) |
| `## ` و `###` | عنوان قسم (بخطين جانبيين) وعنوان فرعي |
| جدول Markdown | جدول بهوية وشلي (رأس موف غامق وصفوف متبادلة) |
| `> نص` | صندوق ملاحظة. يبدأ بـ ⚠️ فيصير صندوق تنبيه، وبـ ✅ صندوق نجاح |
| ✅ ⚠️ ❌ | تتحول لأيقونات (الخطوط لا تحتوي إيموجي) |
| `<!-- pagebreak -->` | فاصل صفحة (يُقبل أيضاً `\newpage`) |
| `:::card عنوان` ... `:::` | بطاقة بيضاء بحد وردي |
| `[[نص]]` و `[[~نص]]` | شارة ممتلئة وشارة شفافة |
| قوائم، قوائم مرقمة، `كود`, `**عريض**` | كما هو متوقع (القوائم المتداخلة بمسافتين تُقبل) |

أي إيموجي غير ✅ ⚠️ ❌ لن يظهر في الـ PDF. تجنبه في الملفات.

## تعديل ربط الملفات

الربط كله في `build/books.json`:

```json
{
  "output_dir": "final",
  "books": [
    {
      "output": "01-تصور-الموقع.pdf",
      "title": "عنوان الغلاف",
      "subtitle": "سطر تحت العنوان (اختياري)",
      "kicker": "عرض مشروع",
      "sources": ["docs/01-site-explanation.md", "docs/02-vision-proposal.md"]
    }
  ]
}
```

- `sources` بالترتيب الذي تظهر به الملفات. كل ملف يبدأ بصفحة جديدة.
- لإضافة صفحة فاصلة بعنوان "ملحق" قبل ملف: `{ "path": "docs/03-backend-comparison.md", "kicker": "ملحق" }`.
- لو تركت `title` فارغاً يؤخذ عنوان الغلاف من أول `# ` في أول ملف.
- يمكن إضافة `"date": "2026-11-02"` لتثبيت تاريخ الغلاف.
- العينة لها ملف مشابه: `build/sample/books.json`.

## هيكل المجلد

```
build.py            الأداة
books.json          ربط الملفات الحقيقي
template/           style.css (الهوية) و fonts.css
fonts/              Cairo (300-800) و Great Vibes (محلية، ترخيص OFL)
sample/             ملفات تجريبية و out/ (PDF العينة)
```
