# عرض موقع براند Alaa Mahjob

مشروع إعداد **عرض كامل** لعميلة (مصممة أزياء سودانية) عشان نبني ليها موقع متجر إلكتروني لبراندها، بنفس تقنية ونظام موقع **وشلي (Wishly)** الجاهز.

المطلوب من هذا الريبو **ملفين PDF نهائيين**، بألوان وهوية وشلي:

| # | الملف النهائي | الغرض |
|---|---|---|
| 1 | `final/01-تصور-الموقع.pdf` | شرح موقع وشلي كنموذج + التصور الكامل لموقع براند Alaa Mahjob + تفاصيل المشروع + شرح الخطتين (مجانية ومدفوعة) |
| 2 | `final/02-الأسعار-والخطط.pdf` | تفاصيل الخطة المجانية والمدفوعة، تكاليف الاشتراكات والدومين، سعر الشغل، وكم يخلص |

## هيكل الريبو

```
README.md            ← انت هنا
CONVENTIONS.md       ← قواعد الشغل المشتركة (اقراه قبل أي مهمة)
brief.md             ← الحقائق المتفق عليها (العميلة، السعر، المدة)
assets/              ← شعار ألاء
shared/              ← مراجع جاهزة: تحليل وشلي + دليل الهوية + ملاحظات البراند
tasks/               ← 5 ملفات مهام، لكل حساب مهمة
docs/                ← مخرجات كل حساب (ملف Markdown لكل مهمة)
final/               ← الملفين النهائيين (المشرف فقط)
```

## طريقة الشغل

- **المشرف** يجهّز الريبو والمهام، ثم يدمج مخرجات الحسابات ويصدر الملفين النهائيين.
- **5 حسابات** كل واحد ياخد ملف مهمة واحد من `tasks/`، يشتغل على **branch خاص بيه**، ويرفع مخرجه في `docs/`.
- ما في حساب يعدّل ملف حساب تاني. لو لقى خطأ في شغل غيره يكتبه في آخر ملفه تحت عنوان **"ملاحظات للمشرف"**.

## مشروع الموقع (Vite)

مجلد [`site/`](site/) فيه مشروع الموقع نفسه محوّلاً إلى Vite (متجر + لوحة تحكم)، ومهامه في `site/tasks/`. قواعد التحويل في `site/MIGRATION.md`.
