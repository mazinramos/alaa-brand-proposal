# مهمة R2: تحويل هوية لوحة التحكم إلى براند ألاء

> **المسارات نسبة إلى مجلد `site/`.** كل أوامر `npm` تُشغَّل داخله.

- **الحساب:** 2
- **الـ branch:** `acct-2-admin-rebrand` (من آخر `main`)
- **ملفاتك فقط:** `admin/index.html` و`src/admin/**`
- **اقرا أولاً:** `REBRAND.md` (القواعد كلها هناك)، `src/shared/brand.js`، و`../docs/02-vision-proposal.md` (القسم 8: لوحة تحكم ألاء)

## المطلوب

حوّل `admin/index.html` و`src/admin/main.js` من هوية وشلي إلى هوية براند ألاء:

1. **الـ head والعناوين:** `<title>` والاسم داخل اللوحة (الشعار وشاشة الدخول والترحيب مثل "وشلي النهاردة") بالاسم الجديد من `brand.js`.
2. **التصنيفات:** القائمة المكتوبة في اللوحة (توزيعات أفراح، خطوبة...) تُستبدل بالمقروء من `categories` في `brand.js`، ويُستعمل كل `key` كما هو. **المتجر (حساب 1) يقرأ نفس القائمة**، فلا تغيّر الأسماء أو المفاتيح.
3. **الإعدادات الافتراضية (`settings`):** الهاتف والإيميل من `brand.js`. كود الدولة `249` وبقية القيم الرقمية تبقى.
4. **قوالب الرسائل (messageTemplates) والنصوص الافتراضية:** أي نص يذكر الهدايا أو التوزيعات أو الاسم القديم يتحول لنص أزياء بالاسم الجديد. حيث تحتاج معلومة ما عندك اكتب نصاً عاماً وعلّمه بتعليق `// TODO-ALAA:` ولا تخترع حقائق.
5. **الفواتير والتصدير (PDF وCSV):** ترويسة الفاتورة والاسم وأسماء الملفات المصدّرة تبدأ بـ `brand.exportPrefix` بدل الاسم القديم، ولا يبقى أي رقم أو إيميل قديم.
6. **أي مثال في الواجهة** (placeholder داخل حقل، نص مساعدة، أمثلة منتجات) يتحول لأمثلة أزياء.
7. **نموذج المنتج في اللوحة (الحقول):** لا تغيّره في هذه المهمة. المقاسات والألوان ميزة لاحقة.

## تحقق قبل التسليم

- `npm run build` ينجح.
- `grep -rniE 'wishly|وشلي' admin src/admin` يعطي صفر نتائج (وفتّش كمان عن أي رقم أو إيميل غير الرموز المؤقتة، وعن `.csv` و`backup` وأسماء الملفات).
- `npm run dev` وافتح `/admin/`: شاشة الدخول بالاسم الجديد بلا أخطاء console.
- لا تدخل بحساب حقيقي ولا تكتب بيانات.
