# مهمة 5: التنظيف النهائي والمراجعة

> **المسارات نسبة إلى مجلد `site/`.** كل أوامر `npm` تُشغَّل داخله.
> **لا تبدأ إلا بعد ما المشرف يدمج مهام R1 وR2 وR3 و4 في `main`.** لو `main` ما فيه `tests/brandcheck` أو `src/shared/brand.js` أو `docs/ARCHITECTURE.md`، توقف وأخبر صاحب المشروع.

- **الحساب:** 5
- **الـ branch:** `acct-5-cleanup` (من آخر `main`)
- **المسموح لك:** أي ملف داخل `site/` لغرض التنظيف أدناه فقط، و`docs/REVIEW.md`
- **اقرا أولاً:** `REBRAND.md`

## المطلوب

1. **شغّل الفحص:** `npm ci && npm run build && npm run brandcheck`. وسجّل النتيجة.
2. **صفّر الأثر القديم:** احذف `legacy/` و`tests/parity/` و`MIGRATION.md` وسكربتات `parity*` من `package.json` (وحزمة `@playwright/test` لو ما عاد لها استعمال بعد حذف الـ parity، وعدّل `package-lock.json` عبر `npm uninstall` وليس يدوياً)، وشيل هذه المسارات من استثناءات `brandcheck` ليفحص كل `site/` ما عدا `node_modules/` و`dist/`. لا تحذف `REBRAND.md` و`tasks/` قبل ما المشرف يقرر.
3. **أعد الفحص** بعد الحذف: `npm run brandcheck` لازم يمر بصفر نتائج. أي نتيجة تُصلح بإزالة النص القديم أو استبداله بالرمز المؤقت المناسب، ولا تغيّر منطق الكود.
4. **راجع بعينك** (`npm run dev`): المتجر وشاشة دخول اللوحة بنفس الألوان والتخطيط، والتصنيفات في المتجر مطابقة لما في اللوحة (من `brand.js`)، ولا أخطاء console جديدة.
5. **`docs/KNOWN-ISSUES.md`:** تأكد إنه ما يذكر الاسم القديم ولا يشير لـ `legacy/`. أعد صياغة أي بند يشير للأصل ليصف المشكلة في كود المشروع الحالي، مع رقم السطر.
6. **`docs/REVIEW.md`:** جدول: البند | الحالة | الدليل (مخرجات الأوامر). وقرار نهائي: **نظيف وجاهز** أو **غير جاهز** مع الأسباب.

## قيود

- لا ميزات ولا تحسينات.
- لا تلمس `../` (ما فوق `site/`).
- لو الفحص يحتاج حساب أدمن ما عندك، صنّف تبويبات اللوحة "غير مفحوصة".

## التسليم

ارفع على الـ branch المحدد، وابدأ رسالتك بسطر التقرير بالصيغة المذكورة في `REBRAND.md` (`تقرير الحساب رقم 5 | ...`).
