# مهمة R3: أداة فحص الهوية (brandcheck)

> **المسارات نسبة إلى مجلد `site/`.** كل أوامر `npm` تُشغَّل داخله.

- **الحساب:** 3
- **الـ branch:** `acct-3-brandcheck` (من آخر `main`)
- **ملفاتك فقط:** `tests/brandcheck/**` وسطر السكربت في `package.json` (`brandcheck`)
- **اقرا أولاً:** `REBRAND.md`، خصوصاً قسم "القائمة المحظورة"

## الهدف

أمر واحد `npm run brandcheck` يثبت إن مشروع ألاء **نظيف من أي أثر لوشلي**. هو الحَكَم في قبول مهام الهوية.

## المطلوب

1. **يفحص** كل ملفات `site/` النصية **ما عدا**: `node_modules/` و`dist/` و`legacy/` و`tests/parity/` و`MIGRATION.md` و`REBRAND.md` و`tasks/` و`package-lock.json` ومجلد الأداة نفسها. (هذه الاستثناءات مؤقتة وتُقلَّص في التنظيف النهائي.)
2. **ويفحص** مخرجات `dist/` لو موجودة (بعد `npm run build`)، بدون استثناءات.
3. **يبحث عن** (غير حساس لحالة الأحرف، وبالعربي والإنجليزي):
   - الاسم القديم بأشكاله (إنجليزي وعربي، وبصيغ مثل `wishly-` و`Wishly_`).
   - نطاق الإيميل القديم `wishly-atelier` وكل إيميل ما عدا الرمز المؤقت `ALAA_EMAIL`.
   - أرقام الهاتف والواتساب القديمة: `0904298584` و`249904298584` و`904298584`.
   - حسابات التواصل القديمة: `wishlygift.favors` و`wishly.sd`.
   - كود `google-site-verification` وقيمته.
   - معرّفات Firebase القديمة: `wishly-82ae9` و`twins-30485`.
   - أي رابط `wa.me/` رقمه ليس الرمز المؤقت `ALAA_WHATSAPP_NUMBER`.
   - أي `apiKey` أو مفتاح يشبه مفاتيح جوجل (`AIza...`).
4. **قاعدة مهمة:** الأداة نفسها تحتوي هذه الأنماط، فلازم تُكتب بشكل لا يجعلها تكتشف نفسها (مثلاً تقسيم النص أو الاستثناء الصريح لمجلدها).
5. **المخرج:** جدول بالملف والسطر والنمط والنص المطابق. رمز الخروج `0` لو نظيف و`1` لو في نتائج. رسائل بالعربي.
6. **تقرير إضافي (تحذير لا خطأ):** يعدّ الرموز المؤقتة المتبقية (`ALAA_*`) وأين، لنعرف شو بقي ننتظره من ألاء.
7. **اختبار ذاتي:** `npm run brandcheck:selftest` يبني ملف تجريبي فيه كل نمط ويتأكد إن الأداة تكتشفه، وإن ملفاً نظيفاً يمر.

## قيود

- لا تعدّل أي ملف خارج `tests/brandcheck/**` وسطري `brandcheck` و`brandcheck:selftest` في `package.json`. لا تضف حزماً (استعمل Node فقط).
- لا تصلح نتائج الفحص بنفسك. فقط أبلغ عنها.

## التسليم

اكتب في `tests/brandcheck/README.md` طريقة التشغيل وتفسير النتائج. ارفع على الـ branch المحدد، وشغّل الأداة على `main` الحالي (المتوقع: ستجد نتائج كثيرة لأن الهوية لم تتحول بعد) وضع الأعداد في التقرير. ابدأ رسالتك بسطر التقرير بالصيغة المذكورة في `REBRAND.md` (`تقرير الحساب رقم 3 | ...`).
